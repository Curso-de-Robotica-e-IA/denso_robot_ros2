# DENSO VS050 IKFast plugin

This package contains one analytic IKFast solver for the nominal six-axis VS050
chain from `base_link` to `J6`. The generated equations contain geometry, not
ROS link names, namespaces, or attached-tool degrees of freedom.

MoveIt may instantiate the same plugin for multiple VS050 planning groups. Set
`link_prefix` independently for each instance, for example `left_` and
`right_`. An end effector attached through fixed joints is handled by the
wrapper's fixed transform between the requested tool frame and `J6`; it does
not require another generated solver.

## Generated and maintained files

- `src/vs050_ikfast_solver.cpp` is generated by OpenRAVE and should not be
  edited manually.
- `include/ikfast.h` is the standard OpenRAVE IKFast support header.
- `src/vs050_ikfast_moveit_plugin.cpp` started from MoveIt's generated wrapper
  and is now maintained here. It contains prefix handling, measured-state
  normalization, and solution-ranking policy.

Do not run MoveIt's plugin generator over this package: it would overwrite the
maintained wrapper. If the VS050 geometry changes, regenerate only the analytic
solver in a temporary location, review it, and replace
`src/vs050_ikfast_solver.cpp`.
